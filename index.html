Agentic shopping, end to end

This page is a Universal Commerce Protocol agent. It runs entirely in your browser: no server, no API key. It reads a merchant's published UCP profile, negotiates a version, searches both Shopify's cross-merchant global catalog and the merchant's own storefront catalog, assembles a real cart, and converts it into a real, merchant-priced checkout. Every request is shown verbatim in the protocol log at the bottom.

The cycle runs to a real, priced checkout and stops there — complete_checkout is the one call that needs a credential this page deliberately does not hold. Nothing is purchased, and no card details are ever collected here.
